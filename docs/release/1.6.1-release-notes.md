## Upgrade

| You track | You get |
|---|---|
| `stable` (`--channel stable`) | 1.6.1, then the monthly 1.6.1.N releases |
| `dev-branch` (`--channel patches`) | the 1.6 patches, as before |
| `master` | the 1.6.1 release, pinned to FOS `1.6.1` |

Upgrade with `bin/updatefog.sh`, or with `git pull` and `bin/installfog.sh`. The
schema moves from 446 to 473. The web UI asks for the schema update after the
upgrade, as usual.

The installer now downloads udpcast from FOGProject/udpcast and checks its
sha256. For an offline install, put `udpcast-v20250223-fog.1.tar.gz` and its
`.sha256` in `packages/` before you run the installer.

These notes cover every change since 1.6.0. The monthly releases already
shipped some of them: #2033 – #2036 in `1.6.0.14`, and #2042 – #2092 in
`1.6.0.158`.

## Highlights

- **IPv6.** The installer sets up IPv6 listeners, a certificate, and opt-in DHCPv6
  (#2160, #2168). Boot chains to the IPv6 address (#2173, #2174). Multicast runs over
  IPv6 (#2172). Every URL that holds an IPv6 address is bracketed (#2157, #2165). FOS
  1.6.1 adds IPv6 and udpcast over IPv6.
- **Software management through the fog-agent.** Install or uninstall per host and per
  group (#2136), with Flatpak, Snap, and winget backends (#2079, #2159), an Exclusive
  level (#2150, #2151), per-OS lists on a dual-boot host (#2146, #2147), one grid per
  page (#2149, #2139), and one entry per package (#2132).
- **Storage nodes.** Deploys balance across a group (#2082). A full node overflows at
  PXE boot (#2103, #2108). Per-node SSH and FTP ports, and SSH key authentication
  (#2060, #2062, #2063).
- **AD rejoin and OU placement** for deployed images (#2042, #2048, #2049, #2122,
  #2125, #2142).
- **Roles can limit the networks** their members use the web UI and API from (#2109).
- **Imaging Report records deploys and multicast joins to unregistered hosts** (#2177,
  FOS #211). "Deploy image now" after Full Registration deploys in the same boot, with
  no reboot through PXE (FOS #211, #2185).
- **MySQL 8.0.13+** installs and upgrades (#2121).
- **Server address move.** The installer follows a server that changed address (#2128,
  #2131, #2133, #2135, #2137).

## Security fixes

| Advisory | Severity | First stable release with the fix |
|---|---|---|
| `GHSA-97vv-f7hc-rp5m` Unauthenticated disclosure of AD join credentials | high | `1.6.0.158` |
| `GHSA-666x-5fjv-v8j9` Unauthenticated token harvest yields AD join credentials and product keys | high | `1.6.0.158` |
| `GHSA-q38j-qx5x-w25v` Legacy Restricted user reads AD join password, product keys and Windows keys | high | `1.6.1` |

- AD join password and product key go only to a vouched key or a declared network
  (#2055, #2077).
- Host secrets are never returned by the API. AD defaults need host write (#2140).
- Reports: Product Keys needs `host.edit` (#2141).
- Agent enrollment: a MAC alone no longer vouches for another machine (#2104). A token
  never approves an identity conflict (#2118). CSRF on every suffixed handler, and CSR
  signatures verified (#2148).
- Never write or follow a link in the staging directory as root (#2102).
- Registration: AD defaults need a FOG login that may create hosts (#2054).

## Installer

- udpcast comes from FOGProject/udpcast, release `v20250223-fog.1`. The installer
  downloads and sha256-checks it, like the plugins. A failed fetch or a failed unpack
  stops the install (#2181, #2182, #2183). The server's `udp-sender` and FOS's
  `udp-receiver` are built from the same source. #2183 also checks the fifth try of the
  plugins download.
- Check PHP before an upgrade changes anything (#2154).
- Install the MariaDB `-compat` packages; probe with `SELECT 1` (#2117).
- Set its own umask and repair servers installed under 027 (#2166, #2167, #2169,
  #2170, #2171).
- Keep FOG's NFS exports in `/etc/exports.d/fog.exports` (#2061).
- Move a stale `sites-enabled` vhost out of Apache's way (#2075).
- Fetch plugins on a storage-node install (#2050).
- HTTPS netboot with a private CA: no signed shim chain (#2065); a forced
  `--netboot-proto` survives the first-install mode answer (#2066); name the
  `sbsign --addcert` gap (#2081).
- Re-issue the Web CA for IPv6 only with `--reissue-web-ca` (#2162, #2163, #2164).
- Drop the `lsb_release` step (#2124). Purge only the PHP Apache module from ondrej
  packages (#2096).

## Fog-agent

- Self-update defaults to Latest (#2078). A lab build never moves to an older release
  (#2053).
- Enrollment through a shared USB adapter (#2116). A pending key's MAC list can change
  (#2052).
- One agent key per OS on a dual-boot host (#2120). Directory hash stored only for the
  directory seat (#2143).

## Imaging and boot

- FOS 1.6.1: IPv6 (FOS #208, #209), udpcast over IPv6 (FOS #210), the OS family
  (FOS #205, #206), Secure Boot enroll fixes (FOS #202, #203), and the boot token for
  unregistered-deploy logging (FOS #211).
- `hostgetkey.php` answers a host that has a queued task (#2185).
- A shared USB adapter no longer rewrites another host's UUID (#2100). SMBIOS identity
  register mode for shared adapters (#2111).
- The OS family is sent to FOS as `osfamily` (#2085, #2086).
- Snapins: Run before software, and Stop snapins if software fails (#2112, #2113).
  Deploy cancels leftover snapins; Capture waits for them (#2127, #2134).
- Multicast: the server's udpcast checks the 32-bit range of a numeric IPv6 scope
  (#2181). Multicast Session Timeout stored in seconds (#2114).
- iPXE pinned to `v2.0.0-fog.10`; the ESP kit script gets the same DHCP pin (#2155,
  #2156).

- Task modal shows a failed fetch's reason instead of hanging (#2091).

## Plugins (fog-plugins `v1.6.31` → `v1.6.32`)

- OIDC sign-in works with a provider whose issuer ends in a slash, such as Authentik.
  The issuer is kept as typed and compared exactly, per the OpenID Connect spec. Found
  and fixed by @ASPePeX (fog-plugins #49). Pinned by #2180.
- The Windows key stays out of every API payload, and the Export Windows Keys report
  needs `windowskey.edit` (fog-plugins #47, #48; `v1.6.31`, pinned by #2144).

## Scheduler, schema, and internals

- Request parameters are read through one helper, `$_POST` then `$_GET`, in place of
  `$_REQUEST`. A cookie can no longer supply a parameter (#2184).
- FOGCron: bad rows, range steps, and Sunday matching fixed (#2073); schedules are
  evaluated like cron, in the install's zone (#2138).
- Upgrade from 1.5: seed missed settings and repair skipped rows (#2057, #2074).
  Normalize legacy values before a rename (#2034).
- PDODB reports the failing statement's error code (#2119).
- Certificate signing says why it failed and writes no serial file (#2099, #2101).
- Default storage group uses `minId()` (#2072). Dead FOGSSH/FOGFTP reuse checks
  removed (#2071).
- Version: `master` reports the release pin, `stable` its release tag (#2033, #2036).
- FOGUpdater Beta tracks the newest `working-*` branch (#2043).
